# Castanhal — Contexto do Cliente

## Contexto base — Solz Lab
Antes de qualquer tarefa, ler:
- `../../_contexto/empresa.md` — quem é a Letícia e como trabalha
- `../../_contexto/preferencias.md` — tom de voz, estilo e o que evitar

O contexto do cliente complementa a identidade da Solz, não substitui.

---

## O que é

Cliente sob demanda. Não há escopo fixo — os projetos são solicitados conforme a necessidade.

**Exemplos de projetos anteriores:** stand, idealização de campanha, peças avulsas.

## Como funciona

Cada projeto é independente. Criar uma pasta dentro de `projetos/` com o nome do projeto ao iniciar.

## Arquivos úteis

- `projetos/` — um subdiretório por projeto entregue
