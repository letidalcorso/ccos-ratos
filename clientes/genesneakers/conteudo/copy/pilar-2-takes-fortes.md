# Pilar 2 — Takes fortes

> A marca tem ponto de vista. Afirma — não explica. Gera compartilhamento, atrai quem pensa igual.
> Formatos: Reel texto, TikTok, carrossel de opinião.

---

## Peça 2.1 — Reel/TikTok: Acesso

**Tema:** Acesso é sobre timing — quem está no lugar certo na hora certa
**Formato:** Reel/TikTok 15–20s. Texto progressivo na tela, fundo preto, tipografia grande. Sem fala obrigatória — funciona mudo (legenda).

**Roteiro:**

| Tempo | Texto na tela |
|---|---|
| 0–2s | "O drop saiu." |
| 3–5s | "Você soube." |
| 6–8s | "A Gene já tem." |
| 9–11s | "Isso é acesso." |
| 12–14s | Logo Gene |

**Direção visual:** texto surge em cortes secos, sem efeito de digitação. Fonte grande, centralizada. Fundo Carbon sólido.

**Caption:**
Acesso não é sorte. É com quem você está. Encomenda aberta.

---

## Peça 2.2 — Carrossel: Quem sabe o que quer não espera

**Tema:** O sneakerhead que age antes da janela fechar
**Formato:** Carrossel Instagram (5 slides)
**Direção visual:** layout de afirmação — tipografia grande, sem foto. Cada slide é uma frase, não um parágrafo.

**Slides:**

| Slide | Texto |
|---|---|
| 1 (capa) | "Quem sabe o que quer não fica esperando chegar." |
| 2 | "O modelo certo aparece. A janela fecha." |
| 3 | "Colorway esgota. Tamanho some. Depois é resell." |
| 4 | "Na Gene você encomenda antes disso acontecer." |
| 5 (CTA) | "Encomenda aberta. Manda mensagem." |

**Caption:**
O par certo não espera por você. Mas a gente espera. Link na bio.

## Peça 2.3 — Reel/TikTok: Reação a drop global

**Tema:** Colorway nova do Nike Dunk — acesso agora, sem espera
**Formato:** Reel/TikTok 15–20s. Imagem do tênis + texto progressivo. Fundo escuro, cortes secos.

> **Instrução de uso:** esse roteiro é reutilizável — toda vez que um drop relevante sair globalmente, adaptar e publicar com o modelo da vez.

**Roteiro (Nike Dunk):**

| Tempo | Visual | Texto na tela |
|---|---|---|
| 0–3s | Foto do Dunk — colorway nova | — |
| 4–5s | Corte | "Novo Dunk. Saiu agora." |
| 6–8s | Mantém imagem | "Chega aqui quando?" |
| 9–11s | Corte para fundo escuro | "Na Gene tem." |
| 12–13s | — | "Encomenda aberta." |
| 14–15s | Logo Gene | — |

**Caption:**
Novo Dunk. Sem espera, sem resell. Manda mensagem.
