— 01 / Mental Model

A hélice é a frase.
As variações são o tom.

A marca Gene nasce de uma metáfora densa: cada tênis tem um código genético — origem, fábrica, drop, cultura. Até agora, esse código estava só no logo. O sistema expandido transforma a hélice em uma família de formas, cada uma servindo um momento de comunicação diferente. É a diferença entre ter uma palavra e ter um vocabulário.

Princípio operante
  • Toda variante nasce da mesma lógica senoidal — coerência visual garantida
  • ACID é sempre frequência, nunca decoração
  • Uma única variante por peça — nunca empilhar duas waves diferentes
  • Big Shoulders declara, IBM Plex Mono anota, wave pulsa
  • Quanto mais barulho no momento (drop, lançamento), mais glow. Quanto mais editorial, mais outline seco
Erros que matam o sistema
  • Usar wave como textura de fundo aleatória
  • Misturar glow + outline na mesma peça
  • Deformar a onda fora da grade senoidal (vira decorativo)
  • Aplicar ACID como fill em áreas grandes (satura a frequência)
  • Esquecer do CARBON como campo. Fundo branco descaracteriza
— 02 / Wave Family

Sete ondas.
Sete momentos.

Cada variação tem um nome, um código, um uso. Nunca improvisar — se o momento não encaixa em uma dessas sete, é porque o sistema ainda não prevê. Nesse caso, proposta de expansão vem antes da aplicação.

— 06 / Motion Principles

Como o
código pulsa.

Motion não é enfeite — é o jeito que a wave respira. Três regras absolutas. Tudo que se move na marca obedece uma delas.

/MOTION-01
Breathe

A wave tem respiração senoidal — ela nunca para, mas também nunca corre. É a pulsação de fundo da marca, como um sinal vital. Hero de landing, story idle, reels intro.

Duração: 3.2s loop
Easing: ease-in-out sine
Movimento: amplitude +/- 8%
/MOTION-02
Scan

Feixe luminoso horizontal que atravessa o frame uma única vez. Momento de revelação — o tênis que aparece, o preço que surge, o CTA que entra.

Duração: 700ms one-shot
Easing: cubic-bezier(0.16,1,0.3,1)
Direção: esquerda → direita sempre
/MOTION-03
Lock

Nada se move. Silêncio absoluto. Usado quando a palavra já carrega o peso — manifesto, declaração, pós-drop. Motion zero É uma decisão de design.

Duração: static
Uso: 1 a cada 5 peças
Razão: contraste é frequência
