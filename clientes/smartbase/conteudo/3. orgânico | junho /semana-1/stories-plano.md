## 🧠 LÓGICA POR TRÁS

Stories não são "preenchimento" — eles são **a sala de espera do feed**. servem pra:
1. **aquecer audiência** antes de cada post grande
2. **interagir** com pergunta/poll/quiz (algoritmo prioriza quem tem retorno)
3. **gerar bastidor** do que tá rolando no feed (mostra processo, humaniza)
4. **construir lista quente** pra paid (quem responde sticker = público engajado)

regra de ouro: **2–4 stories por dia mínimo, em horários diferentes** (manhã/tarde/noite).

## 🎯 STICKERS QUE VOCÊ VAI USAR MAIS (cheat sheet)

| sticker IG | quando usar | objetivo |
|---|---|---|
| **PERGUNTA** | dom 14h, qua durante viagem, sáb 14h | coleta UGC pra responder depois |
| **ENQUETE** | dom 20h, durante a semana ocasional | gera engajamento rápido |
| **COUNTDOWN** | dom manhã (pro post seg), seg/ter pro post comercial fechar | escassez + lembrete |
| **LINK** (whats ou post) | ter (comercial), quartas, sábado | converte intenção em ação |
| **CTA personalizado** ("fale comigo", "veja o post") | ter, qui, sex | manda pra DM/feed |
| **LOCALIZAÇÃO** | qua (viagem) | autoridade geográfica + descoberta |
| **HORA** | sex/sáb relatos | autenticidade |

## ⚙️ COMO POSTAR OS TEMPLATES SVG

1. abre o SVG no Figma/Illustrator/Canva
2. exporta como PNG **1080×1920** (formato story)
3. abre o Instagram → Story → carrega imagem
4. **adiciona o sticker** sobre a área indicada no template (tracejado verde no SVG)
5. publica

⚠️ **importante:** os SVGs deixam **espaço reservado pro sticker** (área pontilhada verde) — não cobre essa área com texto, é onde vai o sticker do IG.
