# Letícia Particular

Espaço pessoal da Letícia — projetos e ferramentas para uso próprio, não relacionados a clientes.

## O que tem aqui

- `vida/` — sistema de vida pessoal (Roda da Vida, foco atual, saúde/emocional). **Privado: fica só local, está no .gitignore, nunca vai pro GitHub.** Tom: próximo e honesto, sem papo de autoajuda; trazer base/evidência. Não misturar com trabalho de cliente.
- `scriptable/` — widgets em JavaScript para o app Scriptable (iOS). Rodam na tela de início e na Central de Controle. Widgets ativos: calendar, greeting, notion-inbox, notion-tasks, notion-today, spotify.
- `capas-notion/` — capas personalizadas para as seções do Notion (marketing, financeiro, administrativo, produtividade, projetos). Arquivo `gerar.js` para gerar novas capas.
- `iphone-setup.md` — guia de configuração do iPhone (apps, atalhos, automações).
- `mockup-iphone.html` — mockup visual do iPhone para apresentações.
- `cockpit-acao-iphone17.md` — plano de ação para iPhone 17.

## Como trabalhar aqui

- Para editar um widget Scriptable: ler o `.js` correspondente, editar, copiar pro app no iPhone.
- Para gerar novas capas do Notion: rodar `gerar.js` em `capas-notion/`.
- Não há cliente envolvido — contexto é pessoal.
