## Rotinas e rituais

Comandos que rodam no dia a dia — automaticamente ou por hábito.

| Skill | Quando usar |
|---|---|
| `/bomdia` | Todo dia ao abrir. Lê Notion, mostra 3 prioridades, sugere início. |
| `/demanda` | ~17h. Lê tarefas "Inbox" do Notion, interpreta e executa: copy → visual. |
| `/planejamento` | Dia 15 de cada mês. Pesquisa tendências por cliente, gera pauta macro. |
| `/atualizar` | Ao fim de sessões longas. Varre o que mudou e atualiza os arquivos de contexto. |
| `/iniciar` | Início de sessão nova quando quiser contexto completo antes de começar. |
| `/syncar` | Sincroniza manualmente o estado do projeto. |

## Codex (OpenAI)

Plugin instalado: `codex@openai-codex`. Usa o GPT-4o/o3 para tarefas de código pesadas — especialmente quando o Claude Code travar ou precisar de uma segunda opinião técnica.

| Skill | Para que serve |
|---|---|
| `/codex:rescue` | Usa quando o Claude Code está preso num bug ou quer uma segunda passagem de diagnóstico. Delega a tarefa ao Codex automaticamente. |
| `/codex:setup` | Configura o ambiente do Codex no projeto. |
| `/codex:codex-cli-runtime` | Runtime do Codex CLI — execução de tarefas de código. |
| `/codex:codex-result-handling` | Como lidar com os resultados devolvidos pelo Codex. |
| `/codex:gpt-5-4-prompting` | Como fazer prompts otimizados para GPT-4/5 dentro do Codex. |

**Quando usar:** para tarefas de desenvolvimento que precisam de poder computacional extra, investigação de bugs difíceis, ou quando quiser comparar abordagens entre Claude e GPT.
